# Birthday Surprise Website 🎂

Aesthetic, responsive birthday mini-site made for an office friend.

## Secret PIN
The PIN is **2209** (22-09).

## Customize
Open `script.js` and change:
- `SECRET` if you want a different PIN.
- The birthday-note text inside `index.html`.
- The wishes in the `wishes` array.

Replace `assets/office-photo.png` with another photo if needed (keep the same filename).

## Run
No build step is required.

Just unzip the folder and double-click `index.html`, or serve it with any simple local server.

Example:
`python -m http.server`

Then open the local address shown by the server.
